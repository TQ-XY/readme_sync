## Introduction

Our Pay API offers a standardised set of endpoints and webhooks that enable ordering platforms to integrate with a customer's chosen gateway. It supports tokenization, authorisation, refunds, and real-time status updates, giving your platform a consistent way to process transactions across our global network of payment partners.<br />
