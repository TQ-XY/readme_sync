## Introduction

A dispatch platform can integrate with Deliverect to offer their courier network across multiple channel types e.g.

- First-party ordering&#x20;
- Delivery service partners (DSPs) where customers opt for 'Self-Delivery'
- POS systems

Courier availability and assignment follow a standardised format to ensure a seamless order experience for delivery. Real-time delivery status updates and tracking capabilities enhance the overall ordering experience.
