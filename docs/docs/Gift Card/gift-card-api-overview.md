## Introduction

The Gift Card API allows you to connect your Gift Card solution to any digital channel integrated with Deliverect including first party ordering channels as well as Deliverect's own 'Direct' ordering channels. It covers the key functions of retrieval,  reemption and reversal of gift card balances.
