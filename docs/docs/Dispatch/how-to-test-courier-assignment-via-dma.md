Use Deliverect's <Glossary>Delivery Manager App</Glossary> to view and manage the fulfillment process for dispatch orders, to start using the app, [Follow the steps in this guide](https://developers.deliverect.com/docs/installing-the-deliverect-app)&#x20;

***

## Using the app

### Manually assign a partner

Choose a delivery partner manually when the app does not assign one automatically.

**Step 1.** Tap the **More order options** button.


<Image src="https://files.readme.io/454bf40-guide_dispatchdma_2.png" alt="Order screen showing the More order options button" align="center" border={true} />


***

**Step 2.** Tap **Choose Delivery Partner**.


<Image src="https://files.readme.io/46d14c0-guide_dispatchdma_4.png" alt="More order options menu with the Choose Delivery Partner option" align="center" border={true} />


***

**Step 3.** Tap **Assign** for the delivery partner you want to use. If available, the app shows the estimated pickup time, delivery time, and price.

The app assigns a delivery partner automatically when the **auto-assign** countdown reaches zero.


<Image src="https://files.readme.io/ea2e3da-guide_dispatchdma_5.png" alt="Delivery partner selection screen showing Assign buttons and estimated pickup details" align="center" border={true} />


***

### View additional order details and make changes

Find the order and tap **More order options**.


<Image src="https://files.readme.io/3121a52-guide_dispatchdma_2.png" alt="Order screen showing the More order options button" align="center" border={true} />


The following is shown:

- Name and telephone number of the courier
- Option to change the delivery address
- Option to locate the courier
- Option to cancel the delivery


<Image src="https://files.readme.io/f933084-guide_dispatchdma_3.jpg" alt="Order details menu showing courier information, delivery address, courier location, and cancellation options" align="center" border={true} />
