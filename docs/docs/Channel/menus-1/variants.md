## Upsells

It is possible for menus to be designed with distinct add-on options to promote upsells. These options may show within e.g. a fixed price meals deal, where some additional priced options are shown e.g "Add drink?"

If configured this way, the flag will show `"isUpsell": true,` and when present can inform the UI of the menu to show clear seperation between required options and optional add ons
